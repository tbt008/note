# 项目笔记库

这是一个个人知识库，用于记录工作内外的学习内容、后端开发知识、项目经验和技术复盘。

## 记录流程

1. 临时想法和未整理内容先写到 `inbox/`。
2. 每周整理一次 `inbox/`，把内容移动到合适的分类目录。
3. 整理时补充背景、结论、示例和后续行动，避免只留下碎片信息。
4. 项目复盘写到 `projects/`，工作流程和协作经验写到 `work/`。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| `inbox/` | 临时记录、待整理素材、阅读摘录 |
| `backend/` | 后端开发知识，如语言、框架、数据库、中间件、架构、部署 |
| `projects/` | 项目背景、方案设计、踩坑记录、上线复盘 |
| `work/` | 工作方法、流程规范、协作经验、会议沉淀 |
| `learning/` | 工作外学习计划、课程笔记、书籍笔记、练习项目 |
| `templates/` | 笔记模板 |
| `assets/` | 图片、截图和其他附件 |

## 文件命名

- 使用小写英文、数字和中划线，例如 `mysql-index-optimization.md`。
- 日期前缀只用于日志和复盘，例如 `2026-10-10-release-review.md`。
- 一篇笔记聚焦一个主题；内容变多后再拆分。

## 常用模板

- 后端技术笔记：`templates/backend-note.md`
- 项目复盘：`templates/project-retrospective.md`
- 问题排查：`templates/troubleshooting.md`
- 学习记录：`templates/learning-note.md`
